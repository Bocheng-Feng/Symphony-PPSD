# Symphony-PPSD

Pseudo Phase Space Density (PPSD) analysis of cold dark matter（CDM）host halos in the **[Symphony Simulation Suite](https://arxiv.org/abs/2109.04476)**.  

---

## Overview
This repository provides tools for measuring, analyzing, and visualizing the PPSD structure of host halos in Symphony, with a focus on connections to halo concentration, accretion history, and deviations from  **Hydrostatic Equilibrium** (HSE).
